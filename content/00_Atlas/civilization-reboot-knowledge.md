## 1. Premise — Bunker Pengetahuan untuk Masa Depan

Hierarki kebangkitan peradaban:

```
Level 0: Pertanian & Pangan        — Tanpa pangan, semua mati
Level 1: Rekayasa Tepat Guna       — Alat dari bahan mentah
Level 2: Kimia & Material          — Sabun, semen, kaca, logam
Level 3: Medis Darurat             — Menyembuhkan tanpa rumah sakit
Level 4: Energi & Komunikasi       — Listrik, radio, informasi
```

**Krisis yang bisa memicu:**

- Pandemi global
- Perang nuklir (EMP)
- Ketergantungan supply chain global
- Collapse infrastruktur internet
- Solar flare Carrington-class

**Tapi catatan ini bukan tentang ketakutan — ini tentang **resiliensi peradaban**.** Setiap link di sini bisa di-_archive offline_ dengan `wget` atau `httrack`.

## 9. Rencana Aksi — Arsipkan Offline

> [!warning] Semua sumber di atas adalah **situs publik**. Sebaiknya di-archive sebelum sesuatu terjadi. Saran teknis:

### Offline Archiving Tools

| Tool             |                     Cara                     | Kelebihan                  | Use Case           |
| ---------------- | :------------------------------------------: | -------------------------- | ------------------ |
| **wget -r -l 5** | `wget -r -l 5 -np -k https://appropedia.org` | Sederhana, semua Linux     | Blog/wiki statis   |
| **HTTrack**      |                  GUI + CLI                   | Mirror penuh dengan relink | Situs besar        |
| **SingleFile**   |              Browser extension               | Satu halaman → satu .html  | Artikel individual |
| **Zotero**       |              Reference manager               | Metadata + PDF             | Paper akademik     |

### Contoh Script Arsip

```bash
#!/bin/bash
# archive-offline.sh — Arsip sumber daya restart peradaban
# BUTUH: sudo apt install wget httrack

SITES=(
  "https://www.appropedia.org"
  "https://lowtechmagazine.com"
  "https://www.opensourceecology.org"
  "https://pfaf.org"
  "https://www.builditsolar.com"
  "https://www.otherpower.com"
  "https://cavemanchemistry.blogspot.com"
)

echo "=== ARSIP OFFLINE ==="
for url in "${SITES[@]}"; do
  domain=$(echo "$url" | sed 's|https://||' | cut -d'/' -f1)
  echo "Archiving $domain..."
  wget -r -l 3 -np -k -p --connect-timeout=10 --timeout=30 \
    -P "archive/$domain" "$url" 2>/dev/null || echo "  ❌ Failed: $domain"
  echo "  ✅ Done: $domain $(du -sh "archive/$domain" 2>/dev/null | cut -f1)"
done
echo ""
echo "Total archive size: $(du -sh archive/ 2>/dev/null | cut -f1)"
```
