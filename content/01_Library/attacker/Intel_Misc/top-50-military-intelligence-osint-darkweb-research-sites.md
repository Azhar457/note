## Important Notes

### Darkweb Access
```
Ahmia.fi dan Torch adalah SEARCH ENGINES — legal untuk diakses.
Mereka index .onion sites yang PUBLIC, bukan private markets.

Untuk akses .onion langsung:
  1. Download Tor Browser dari torproject.org (official)
  2. Verify signature GPG sebelum install
  3. Jangan maximize window (fingerprinting)
  4. Disable JavaScript (NoScript default)
  5. Jangan login ke clearnet account via Tor
```

### Operational Security (OPSEC)
```
Saat research sensitive topics:
  - Gunakan VPN (Mullvad/Proton) atau Tor
  - Jangan login ke personal accounts
  - Gunakan VM isolated (Qubes/VMware)
  - Clear cookies/cache/session setiap selesai
  - Jangan download files dari unknown sources
```

### API Keys
```
Beberapa situs butuh API key (🔒):
  - Shodan: free tier 100 credits/month
  - Censys: free tier 250 queries/month
  - VirusTotal: free tier 4 lookups/minute
  - AlienVault OTX: free, unlimited dengan key
  - ACLED: free untuk non-commercial
  - Dehashed: free tier limited
```
