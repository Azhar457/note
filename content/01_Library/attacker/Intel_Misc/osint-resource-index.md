## 17. Test Validitas & Cara Curl yang Benar

### 🔍 Analisa Proxy Pool vs Direct Curl

**Kesimpulan dari pengujian real dengan proxy pool aktif (localhost:11080-11089):**

| URL | Direct | SOCKS5 Proxy | Kesimpulan |
|:---|:------:|:------------:|------------|
| army.mil | ✅ 200 | ✅ 200 | Cloudflare tidak blokir IP ini dari mana pun |
| defense.gov | ❌ 403 | ❌ 403 | Cloudflare strict WAF — blokir semua proxy known |
| nsa.gov | ❌ 403 | ❌ 403 | Cloudflare strict — mungkin butuh VPN AS premium |
| gchq.gov.uk | ✅ 200 | ✅ 200 | Tidak ada geo-restriction |
| foreignaffairs.com | — | ✅ (via proxy) | Proxy membantu |
| csis.org | — | ✅ (via proxy) | Proxy membantu |

**Root cause 403:**
Proxy pool (SOCKS5) menggunakan IP **free/anonymous proxy** — dan situs .gov/.mil pakai Cloudflare WAF level strict yang sudah memblokir IP proxy known. **Bukan masalah cara curl** — bahkan dengan `-A "Mozilla/5.0..."` (User-Agent spoof) tetap kena 403. Ini karena Cloudflare menggunakan **JA3 fingerprint** dan **IP reputation**, bukan sekadar User-Agent.

### Script Verifikasi dengan Proxy Pool

```bash
#!/bin/bash
# verify-osint-links.sh — verifikasi + rotasi proxy untuk bypas 403
# JALANKAN: bash verify-osint-links.sh
# Gunakan proxy pool aktif (localhost:11080-11089)

urls=(
  "https://www.cia.gov"
  "https://www.cisa.gov"
  "https://www.gchq.gov.uk"
  "https://www.ncsc.gov.uk"
  "https://www.idf.il"
  "https://www.mossad.gov.il"
  "https://www.rand.org"
  "https://www.csis.org"
  "https://www.iiss.org"
  "https://www.brookings.edu"
  "https://www.belfercenter.org"
  "https://www.c4isrnet.com"
  "https://www.defensenews.com"
  "https://www.janes.com"
  "https://warontherocks.com"
  "https://www.foreignaffairs.com"
  "https://foreignpolicy.com"
  "https://theintercept.com"
  "https://www.bellingcat.com"
  "https://citizenlab.ca"
  "https://www.eff.org"
  "https://www.amnesty.org"
  "https://www.hrw.org"
  "https://www.shodan.io"
  "https://www.greynoise.io"
  "https://www.sipri.org"
  "https://www.armscontrol.org"
  "https://fas.org"
  "https://attack.mitre.org"
  "https://osintframework.com"
  "https://inteltechniques.com"
  "https://www.defense.gov"
  "https://www.army.mil"
  "https://www.nsa.gov"
  "https://www.darpa.mil"
  "https://www.fbi.gov"
)

echo "Verifying ${#urls[@]} URLs with rotating SOCKS5 proxy pool..."
echo ""

use_proxy=true
# Cek apakah proxy pool aktif
if ! curl -s --socks5 localhost:11080 --connect-timeout 3 -o /dev/null http://example.com 2>/dev/null; then
  use_proxy=false
  echo "[WARN] Proxy pool tidak aktif — fallback ke direct"
  echo ""
fi

passed=0; failed=0; total=0

for url in "${urls[@]}"; do
  if $use_proxy; then
    port=$((11080 + RANDOM % 10))
    code=$(curl -s -o /dev/null -w "%{http_code}" --socks5 "localhost:$port" \
      --connect-timeout 10 --max-time 15 -L "$url" 2>/dev/null)
    method="SOCKS5:$port"
  else
    code=$(curl -s -o /dev/null -w "%{http_code}" \
      --connect-timeout 10 --max-time 15 -L "$url" 2>/dev/null)
    method="DIRECT"
  fi
  
  if [[ "$code" =~ ^2[0-9][0-9]$ ]]; then
    printf "%-50s ✅ %-8s %s\n" "${url:0:50}" "$code" "($method)"
    ((passed++))
  elif [[ "$code" =~ ^3[0-9][0-9]$ ]]; then
    printf "%-50s 🟡 %-8s %s\n" "${url:0:50}" "$code" "($method)"
    ((passed++))
  else
    printf "%-50s ❌ %-8s %s\n" "${url:0:50}" "$code" "($method)"
    ((failed++))
  fi
  ((total++))
done

echo ""
echo "HASIL: ✅ $passed reachable | ❌ $failed unreachable | Total: $total"
echo ""
echo "NOTE: .mil/.gov sites yang tetap 403 via proxy menggunakan"
echo "Cloudflare WAF dengan IP reputation blocking. Solusi:"
echo "  1. VPN ke AS (bukan proxy) untuk akses penuh"
echo "  2. Atau gunakan AWS EC2 US-based untuk curl dari IP AS"
```
