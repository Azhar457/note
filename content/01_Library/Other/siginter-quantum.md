# SIGINT & Quantum

Persimpangan signal intelligence (SIGINT) dan quantum: (1) **Quantum computing threats** — Shor's algorithm mematahkan RSA/ECC saat qubit cukup (est. 2040-2050, "Q-day"); symmetric (AES-256) tetap aman dengan key size 2x (Grover); (2) **PQC** — NIST standards 2024: ML-KEM (Kyber), ML-DSA (Dilithium), SLH-DSA (SPHINCS+), FN-DSA (Falcon); (3) **QKD** (Quantum Key Distribution) — distribusi key dengan deteksi eavesdrop (BB84); (4) **SIGINT angle** — intercept quantum-ready? Sinyal terenkripsi PQC tetap bisa di-record (harvest now, decrypt later), signal analysis tidak berubah.

Langkah: inventory crypto (kriptografi apa dipakai), migrasi hybrid (classic + PQC), crypto agility (algoritma bisa swap). Lihat juga Quantum_Crypto library section.
