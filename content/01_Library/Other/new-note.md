# New Note (Template)

File ini adalah template note kosong untuk pembuatan catatan baru — struktur yang dipakai: frontmatter (title, tags, aliases, created), heading utama (#), body dengan sections (##), penutup `---` + marker (`audited` jika sudah diverifikasi).

Pola penulisan yang dipakai vault: bahasa Indonesia + istilah teknis Inggris, self-contained (tidak bergantung file lain untuk dipahami), cross-reference via wikilink `[[...]]`, payload contoh inline (bukan path lokal). Ganti isi sesuai topik — jangan biarkan sebagai stub (planned stub note tanpa konten tidak dihitung dalam audit).
