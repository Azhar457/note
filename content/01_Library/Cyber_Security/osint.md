# OSINT — Open Source Intelligence

> [!abstract] Ringkasan
> OSINT adalah pengumpulan intelijen dari sumber terbuka. Catatan ini merupakan hub untuk konten OSINT yang tersebar di vault. Lihat [[hierarchy-search]] untuk struktur lengkap.

## Domain OSINT

- People OSINT: pencarian identitas, social media
- Network OSINT: domain, IP, ASN reconnaissance
- Geolocation OSINT: gambar, video, metadata
- Technical OSINT: Shodan, Censys, leak database
